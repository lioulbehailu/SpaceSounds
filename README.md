# README

This README is an instruction to get SpaceSound up and running.

# SpaceSound

SpaceSound is an immersive VR installation that explores sound design through spatial soundscape creation.

## Technical Details
This is a Unity VR application.
- Unity version: 6000.0.74f1 LTS
- XR Interaction Toolkit: 3.0.10
- XR Plugin Management: 4.5.4
- Compatible with Meta Quest headsets (via Meta Horizon Link) or XR Device Simulator for headset-free testing.

## Setup Instructions

Clone the git repository and make it your current directory:

```bash
git clone https://github.com/lioulbehailu/SpaceSounds.git
cd SpaceSound
```
### Required Plugins& SDKs
Once the git repository is cloned and opened in Unity, Unity installs required packages automatically.


### Running with a Meta Quest headset

1. Install the Meta Horizon Link desktop app
```bash
https://www.meta.com/quest/setup/
```
2. Connect the headset vis USB3
3. Navigate to the Settings and select the "Link to PC" option using a USB
4. Hit Play in Unity

### Running without a headset
1. Enable the XR Device Simulator in the project hierarchy
2. Hit Play in Unity
> **Note:** Do not enable the XR Device Simulator while using a VR headset.
